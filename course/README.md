# 교육자료 관리

교육자료 기준본은 이 폴더의 `index.html`입니다. 대시보드의 **교육자료** 메뉴는 이 파일을 그대로 표시합니다. 이미지도 파일 내부에 포함되어 있습니다.

## 수정 순서

1. AI에게 `course/index.html`의 수정할 회차와 내용을 요청합니다.
2. AI가 현재 파일을 읽고 수정한 뒤 JavaScript 문법과 이미지 포함 여부를 확인합니다.
3. 변경을 Streamlit에 연결된 GitHub 브랜치에 반영합니다.
4. Streamlit이 새 커밋을 가져오면 교육자료에도 반영됩니다. 열려 있는 교육자료 화면은 60초마다 파일 변경을 확인합니다.

별도의 교재 업로드나 외부 HTML 호스팅은 필요하지 않습니다. Streamlit의 GitHub 동기화가 먼저 완료되어야 하므로 커밋 시각부터 60초 이내 반영을 보장하는 것은 아닙니다.

이미지의 `data:image/...;base64,...` 내용은 교체 요청이 없는 한 유지합니다. API 키·계좌 정보·비밀번호는 이 파일에 넣지 않습니다.

로컬 또는 다운로드한 HTML만 수정하면 사이트는 바뀌지 않습니다. 반드시 이 저장소의 기준본에도 반영합니다.
